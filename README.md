# Viabilidad económica y financiera de la instalación de un sistema fotovoltaico en el supermercado Akí Latacunga Norte

## Pregunta del desafío

¿Es económicamente y financieramente viable instalar un sistema fotovoltaico en el supermercado Akí Latacunga Norte?

## Tecnologías utilizadas

- Next.js
- TypeScript
- React
- CSS
- Node.js y npm para la gestión de dependencias mediante `package.json`

## Estado actual

**Estructura inicial en desarrollo.**

El proyecto contiene la base documental, la organización de datos y los roles del sistema multiagente. Aún no se han incorporado datos, cálculos financieros ni resultados de viabilidad.
