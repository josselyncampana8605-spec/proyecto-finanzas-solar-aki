# Respuesta rechazada: intento de uso de Python

Fecha: 2026-07-31

## Contexto

Se registró un intento inicial de verificar el acceso a páginas oficiales mediante un script en Python. La ejecución fue rechazada por el estudiante porque este proyecto no utiliza Python y la acción no corresponde al flujo previsto para la investigación documental.

## Decisión del estudiante

El estudiante detectó que la inteligencia artificial intentó emplear una tecnología no prevista para este proyecto, rechazó la acción y mantuvo la ejecución exclusivamente dentro del entorno de TypeScript/Next.js del repositorio.

## Implicación

La recopilación de fuentes oficiales se continuará sin ejecutar código Python, sin instalar librerías de Python y sin introducir herramientas ajenas al stack del proyecto. En caso de que una página no sea consultable automáticamente, se registrará como "acceso automático no disponible" y se continuará con la documentación sin inventar información.
